## Writeup Standards

To keep notes reproducible and actionable:

1. **Recon First:** Every writeup starts with the raw input, headers, or binary metadata before jumping to conclusions.
2. **Deterministic Exploits:** Proof-of-concept scripts (Python or Bash) are provided so steps can be replayed and tested.
3. **Spoilers Hidden:** Flags are placed inside blur-to-reveal blocks so writeups can be used as hints without spoiling the final answer immediately.
