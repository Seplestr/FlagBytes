# CTF Writeups

## Introduction to CTFs

Capture The Flags (CTFs) are cybersecurity challenges designed to help people learn and practice different security concepts in a practical way.

These challenges usually involve:

- Linux basics
- Networking
- Cryptography
- Web exploitation
- Reverse engineering
- Forensics
- Scripting and automation

Most challenges require finding a hidden flag in the format:

```text
flag{example_flag}
```

## How I Started

I started learning cybersecurity mainly through beginner-friendly CTF platforms like:

- picoCTF
- CyLab Security Academy

These platforms helped me understand:

- how to approach challenges
- basic Linux commands
- enumeration techniques
- problem solving methodology

At the beginning, even simple challenges felt confusing because I didn’t know:

- which tools to use
- where to start
- how to analyze files
- how to search for clues

Over time, I slowly became more comfortable with:

- using Linux
- reading challenge descriptions carefully
- checking files and outputs
- researching unfamiliar concepts

## Why I Started Writing Writeups

I created these writeups mainly to:

- track my learning progress
- revise solved challenges later
- document tools and commands I used
- improve my problem-solving approach

These writeups are written while learning, so some methods may not always be the most optimized ones.
